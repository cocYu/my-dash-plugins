# 截图工作台

在工具箱打开「截图」。不配置 AI 也可以截图、标注、贴图、导出和管理历史。

- **区域截图**：在触发时鼠标所在的显示器上冻屏。拖动框选，或用 Enter 选全屏；开始标注前可用「微调选区」输入位置和尺寸（逻辑像素），工具条显示最终图像的物理像素数。编辑时 Enter 复制、Esc 取消，有标注时需再次确认。
- **全屏 / 窗口**：在预览列表选择来源。全屏截图会先隐藏工作台。也可以从剪贴板或本地图片文件开始编辑。
- **延时 / 快捷键**：区域截图可等待 3、5 或 10 秒后取屏，适合截取菜单；在设置中可另行启用系统级区域截图快捷键。
- **标注**：画笔、高亮、线、箭头、矩形、椭圆、文字、步骤号、马赛克。选择工具可移动标注，Delete 删除；Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。
- **步骤说明**：选择「步骤」，设置编号直径（12–128 px）。关闭「附带文字」时单击放置编号；开启后，先点编号位置，再移动鼠标预览引线、点击文字位置，输入说明后按 Enter。Esc 取消未完成的步骤，不占用编号。编号、引线和说明一起移动、删除和撤销。
- **截图外观**：在冻屏工具条或工作台中打开「截图外观…」，预览 PNG 的圆角（半径 0–256 px）和外壳。选择「不带壳」或关闭圆角可恢复本次编辑的原貌，不影响标注。设置页可指定新截图的默认值；已导出的 PNG 是合成图片。
- **滚动长截图**：框选内容区，尽量避开固定标题栏、滚动条和动画。进入「滚动长截图」后向下滚动，保留一部分与上一屏重合的内容，再点「抓取下一屏」。自动翻页仅支持 macOS，需要辅助功能权限；无权限时可手动抓取。重复帧不会增加高度。拼接完点「完成并标注」即可在工作台编辑整张长图：可以滚动到下半段添加步骤、马赛克或文字，再调整圆角和外壳后导出。无需标注时也可以直接复制、保存或贴图。
- **历史 / 导出**：保存 PNG、复制或钉为置顶贴图。历史可按来源筛选，打开旧图后再标注导出会创建新记录，保留原图。设置固定目录后遇到同名文件会自动编号。插件沿用原有设置、历史索引及图片文件，无需迁移。
- **文字与 AI**：本地 OCR 首次需要联网下载引擎和语言包；云端 OCR、翻译、识图需要自行配置供应商，只有主动使用对应功能时才会提交内容。

macOS 如果没有屏幕画面，请在系统隐私设置中允许宿主录制屏幕，再重启宿主。受系统保护的窗口可能无法截取。建议配套使用本次更新的主应用。
